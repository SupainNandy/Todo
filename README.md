- ✏️ **Update Tasks** — Edit existing task details.
- ✅ **Complete Tasks** — Mark tasks as completed.

## 🚀 Getting Started

### Prerequisites

Install the tools required by your project:

- [Node.js](https://nodejs.org/) and npm, if using a Node.js application
- Git
- Any database or additional services required by the application

### 1. Clone the Repository

```bash
git clone https://github.com/SupainNandy/Todo.git
cd Todo
```

### 2. Install Dependencies

```bash
npm install
```

Run this command in the directory containing the relevant `package.json` file. If the repository contains separate frontend and backend folders, install dependencies in each application directory.

### 3. Configure Environment Variables

If your project requires environment variables, create a `.env` file and add the variables expected by your source code.

Never commit passwords, API keys, database credentials, or other secrets to GitHub.

### 4. Run the Application

For a project configured with Vite, use:

```bash
npm run dev
```

For a Node.js backend, use the start command defined in its `package.json`, for example:

```bash
npm start
```

Check your project's scripts before running these commands.
